คำถามที่เจอบ่อย

สั้นๆ ตรงๆ

ต้องมี API key ไหม?

ไม่ต้อง ข้อความและภาพใช้ Pollinations.ai ฟรีโดยตรงจากเบราว์เซอร์ ถ้าอยากได้คุณภาพสูงกว่านี้ค่อยใส่คีย์ OpenAI-compatible ของตัวเองใน ⚙ ตั้งค่า

เหมือน Miora ตรงไหน / ต่างตรงไหน?

เหมือนตรงคอนเซ็ปต์: บรีฟเดียวแตก 4 งานบนแคนวาสเดียว + มี Brand Memory ต่างตรง tier ฟรีนี้ใช้โมเดลเปิดฟรี วิดีโอจึงเป็น “โมชันพรีวิว” ไม่ใช่โมเดลวิดีโอจริง และรันได้แบบสแตติกบน GitHub Pages

Memory เก็บที่ไหน ปลอดภัยไหม?

เก็บแค่ใน localStorage ของเบราว์เซอร์เครื่องคุณ ไม่ส่งไปเซิร์ฟเวอร์อื่น ล้างได้ปุ่มเดียว ย้ายโฮสต์ก็เริ่มจำใหม่ของเครื่องนั้น

เอาขึ้น GitHub ยังไง?

เลื่อนลงหัวข้อถัดไป กดโหลด ZIP สร้าง repo ใหม่ อัปโหลดไฟล์ข้างใน เปิด Settings → Pages → Deploy from branch แค่นั้น ใช้เวลาประมาณ 2 นาที

เอาเว็บนี้ขึ้น GitHub Pages

ไฟล์สแตนด์อโลนชุดเดียวกับหน้านี้ — โหลดแล้วอัปขึ้น repo ได้เลย ไม่ต้อง build

📦

ไฟล์พร้อม deploy แบบไฟล์เดียว

กดปุ่มเพื่อโหลด index.html ไฟล์เดียว (รวม CSS+JS แล้ว) อัปขึ้น repo ได้เลย ไม่ต้อง build

1) โหลด ZIP แล้วแตกไฟล์ จะได้ index.html + styles.css + app.js + README.md 2) ไป github.com → New repository → ตั้งชื่อเช่น aura-studio → Public → Create 3) ปุ่ม Add file → Upload files → ลาก 4 ไฟล์นั้นขึ้นไป → Commit 4) เข้า Settings → Pages → Source: Deploy from a branch → Branch: main, / (root) → Save 5) รอ ~1 นาที เปิด https://<ชื่อคุณ>.github.io/aura-studio/ ได้เลย * อยากใช้โดเมนตัวเอง: ใส่ไฟล์ CNAME แล้วตั้ง DNS ตาม docs ของ GitHub Pages
