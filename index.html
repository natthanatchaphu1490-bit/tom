❓ คำถามพบบ่อย

ฟรีจริงไหม? ต้องสมัครไหม?
ฟรีจริง ไม่ต้องสมัคร ไม่ต้องกรอกอีเมล เปิดเว็บแล้วใช้ได้เลย API ฟรีของ Pollinations แบบไม่ต้องสมัคร
เหมือน Miora ตรงไหน / ต่างตรงไหน?
เหมือนตรงแนวคิด: บรีฟเดียวแตกเป็นภาพ คอนเทนต์ UI วิดีโอ 3D + มี Brand Memory จำสไตล์ ต่างตรงที่เว็บนี้โค้ดใหม่ทั้งหมด ไม่มีระบบล็อกอิน/จ่ายเงิน และวิดีโอให้เป็นสตอรี่บอร์ด+prompt แทนการเรนเดอร์จริง
ข้อมูลแบรนด์ของฉันไปไหน?
อยู่ในเบราวเซอร์คุณเท่านั้น (localStorage) ไม่ส่งไปเซิร์ฟเวอร์อื่น ลบได้ด้วยปุ่ม “ล้างความจำ”
ภาพที่สร้างเอาไปใช้เชิงพาณิชย์ได้ไหม?
โดยทั่วไปทำได้ แต่ควรตรวจเงื่อนไขโมเดล/แพลตฟอร์มอีกครั้งสำหรับงานสำคัญ และอย่าใช้ภาพที่มีโลโก้แบรนด์คนอื่นหรือใบหน้าบุคคลจริงโดยไม่ได้รับอนุญาต
กดสร้างแล้วหมุนนาน / ขึ้น error ทำไง?
รอ 10–60 วินาทีแล้วลองใหม่ อย่ากดรัวๆ เพราะคิวต่อคนมีจำกัด ถ้ายังไม่ได้ให้ลดความยาว prompt หรือเปลี่ยนสัดส่วนภาพแล้วลองอีกครั้ง
